## Descripción del problema
**AulaLogic** es un sistema de consola en Java diseñado para registrar, consultar, procesar y almacenar las calificaciones de los estudiantes de una asignatura. Permite calcular promedios reales, notas máximas y mínimas, estados académicos (`APROBADO` o `REPROBADO`), reportes generales del curso y conservar los registros en `datos/estudiantes.txt` entre ejecuciones.
